About phenomenological models
What is a phenomenological model?A phenomenological model describes epidemic curve shape using a mathematical function chosen for flexibility, not biological mechanism. Parameters are estimated empirically by fitting to observed data.
SSE vs GLM fittingLeast squares (SSE) assumes normally distributed errors. For count data, Poisson or Negative Binomial log-likelihood is more appropriate. Using NB with the epidemic model as the GLM mean function is the statistically rigorous approach when data is overdispersed (VMR > 1.5).
For homework: SSE is fine. For publication: use NB log-likelihood if VMR > 1.5. The fitting objective does not change the model equations — only how parameters are estimated.
Parameter uncertainty and bootstrap CIsFitted parameters are point estimates with uncertainty. Bootstrap CIs quantify this by resampling residuals and refitting 300 times. The histogram of each parameter shows its sampling distribution.
What wide bootstrap CIs tell youWide CIs on K early in an outbreak mean the data has not yet informed final size. Wide CIs on a (Richards asymmetry) often indicate overfitting. Bimodal histograms indicate identifiability problems — the optimizer is finding two distinct solutions.
If histograms are bimodal or extremely wide, switch to a simpler model. Bootstrap takes ~3–5 seconds in browser — the wait is worth the information about parameter identifiability.
